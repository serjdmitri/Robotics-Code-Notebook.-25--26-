Project

Mac Assistant

Relay

Relay is a voice assistant for Mac that can open apps, help with notes and reminders, and interact with interfaces. It combines on-device dictation with an AI agent and asks for confirmation on sensitive actions.

Robotics Personal Project

CarComms

Inspired by a summer robotics program, CarComms explores how autonomous vehicles might sense obstacles and communicate. One Raspberry Pi robot avoids obstacles today; the second robot and vehicle-to-vehicle coordination are still in progress.
