Talk to your Mac.

← All projects
The question

What if asking felt natural?

Relay explores how speech, AI, and computer controls can work together to help with everyday tasks on a Mac.

The approach

From request to action.

On-device dictation turns speech into text. Relay can route requests to instant commands or an AI model and use local tools to help carry them out.

Everyday use

Ask, dictate, and get things done.

Relay can open apps, work with notes and reminders, read a calendar, and help navigate interfaces. Its companion phone interface can send requests to the Mac.

Built with care

Control stays in view.

Relay uses confirmation prompts for actions such as sending messages or moving items to the Trash. The project is still early, and its README distinguishes tested features from flows that need further verification.
